# UU Doomscroller 0.1.57

- With the built-in lists switched off, X finds the next clip much sooner and
  keeps a few ready for the next launch.
- X draws from far more of the web than before, so the same clips no longer come back after a restart.
- Clips that have already played no longer come back after a relaunch.
- A slow search engine no longer holds up the rest of the feed.
