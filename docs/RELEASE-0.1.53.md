# UU Doomscroller 0.1.53

- X keeps going. It used to find a handful of posts and then stop for ten minutes whenever the search engines refused the phone. It now checks each post for a video before lining it up, falls back to posts cited on Wikipedia when the search engines refuse, and carries a small built-in list behind that.
- No more waiting on the face when a clip is already ready. A ready clip now starts by itself; before, some of them sat behind the loading face until you swiped.
- New setting under Sources: "Random letters instead of subjects". On, the app searches for a few random letters instead of a word from its built-in subject lists.
